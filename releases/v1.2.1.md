# Real Life English v1.2.1

- 修复一类导致分类列表空白及词卡无法显示的兼容性问题：不再依赖部分旧版 WebView 缺少的 flatMap、replaceChildren，以及可选链语法。
- Android APK 将启动代码、词库和主程序直接嵌入页面，减少外部脚本加载失败造成的空白问题；图片继续按需离线读取。
- 页面初始化失败时显示提示，并保留“检查更新”的恢复入口。
- 切换分类时默认显示未掌握词，避免之前的待记模式使新分类看起来没有内容。

不清除学习进度，包名和签名保持一致。若 v1.2.0 内按钮也无法使用，请从本 Release 手动下载 APK 覆盖安装，不要卸载。

已针对缺失接口的环境及手机尺寸浏览器测试，APK 检查通过；尚未连接用户手机确认其具体 WebView 版本和实际安装效果。
