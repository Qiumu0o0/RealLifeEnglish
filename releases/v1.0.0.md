# Real Life English v1.0.0

首个 Android 安装包，内置29个水果词卡及对应商品图片，支持中文翻面、待记复习、JSON 词库导入和学习进度保存。已掌握词会退出学习队列。

下载附件 `RealLifeEnglish.apk`，在 Android 6.0 及以上设备上打开安装。

- 离线可用，学习进度保存在应用内，与网页版独立。
- 当前为调试签名版本；签名和内置资源已验证，尚未实机测试。
- 后续版本须使用同一签名及包名，并递增 versionCode，方可覆盖更新。
- 更新需手动下载 APK，不支持自动更新。卸载会清除本地学习进度。

安装包对应源码提交：`45059d4`。
