# Real Life English v1.1.0

- 新增“检查更新”，查询 GitHub 最新正式版本。
- 新版可在应用内下载，再通过 Android 系统确认安装；首次需允许此应用安装更新。
- 下载检查文件大小、SHA-256（GitHub 提供时）、包名和更高版本编号。
- 保持原包名及签名，覆盖安装可保留本地学习进度。
- 网页版按钮提供最新 Android APK 下载入口。

Android 6.0 及以上，调试签名版本。APK 编译、签名及资源检查通过；尚未手机实机验证更新安装流程。

v1.0.0 没有更新按钮，请先手动下载安装此版本；以后可使用应用内按钮检查更新。
