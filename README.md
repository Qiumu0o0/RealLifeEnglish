## 背词应用

在线使用：[打开背词应用](https://qiumu0o0.github.io/RealLifeEnglish/)。

Android：[下载 APK](downloads/RealLifeEnglish.apk)（Android 6.0 及以上；离线可用，调试签名版本）。下载后在手机上打开安装，按系统提示允许此来源安装。

APK 进度保存在应用内，与网页独立；卸载应用会清除。构建说明见 [Android 项目](android/README.md)。

支持图片词卡、中文翻面、待记复习、JSON 词库导入和本地进度保存；已掌握词不会继续出现。

词库：`ColesFruitVocabulary.json`；图片：`images/`。商品图片来自 Coles，来源记录在 `images/sources.json`。

## 项目初衷

这个项目的主要想法是，收集日常生活中会使用到的英语单词和表达，而非考试中会用到的。最初的想法起源于我第一次前往澳大利亚留学时，尽管我已经有一定的英语基础，但是还是遇到了很多我不知道的单词和表达。在思考之后，我认为主要的原因是，我以前的英语学习都是面向考试的，而不是面向真实的生活。

实际在澳大利亚生活了一段时间之后，我觉得超市的货物应该是生活中最实用的英语之一。所以，这个列表就准备从 Coles 的商品开始——毕竟，coles 也算是澳洲的几大商场之一。至于为什么不从 WWls, Aldi 等商场开始，那还是因为我当时最常去的超市就是 Coles. 0o0.

如果大家觉得这个想法很实用，后续也希望结合世界各地的志同道合的朋友们，让这个项目帮助到更多的人！（不只是有去澳大利亚的打算的人~）
