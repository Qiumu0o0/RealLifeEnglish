# Coles 分页采集

本次通过 web.run 实际检查 683 个分页快照，读到 22763 条商品记录；在每个分类中按名称和规格去重后共 16259 条。没有每类 20 词或每类 48 商品的截断。

这不是实时全量库存：分页快照日期、商品总数和排序会变化；部分页没有返回商品。即使页码全部可读，也不能证明某一时刻的全部商品已覆盖。空结果不代表该分类没有商品。

## 文件

- 每类 page-*.json：实际读取的商品名称、规格、页码、来源 URL、页面声明总数；空页也保留。
- 每类 products.json：分类内去重后的商品清单。
- products.json：所有分类的商品清单，保留来源页；跨分类不合并。
- coverage.json：机器可读的覆盖情况与缺失页码。
- [核心词与图片处理说明](TERMS.md)：双语候选、词形差异、已解析商品链接与下载图片；数量见 [terms-summary.json](terms-summary.json)。

## 与 APP 词库的区别

这里保存的是原始商品事实，不是已审核的英语词卡。完整商品名可能包含品牌、口味和规格，不能直接当成核心单词。中文释义、单复数合并以及对应图片仍需核对后才能接入 APP；现有 APP 词库没有被原始清单覆盖。
